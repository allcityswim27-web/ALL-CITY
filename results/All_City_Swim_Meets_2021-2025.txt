Notes on sources
---

All five main pages (swim-2021 through swim-2025) fetched successfully
(HTTP 200) as regular HTML pages, as expected — no PDFs required for the
main results pages in this range.

"Results by Age Group" links: for every year 2021-2025, each age-group
link on the page points directly to a PDF file (e.g.
.../results/2021/swim/girls_8under.pdf), not to a separate HTML page. Per
the task instructions ("if an age-group link leads to a separate page,
follow it and extract that too"), none of these links led to a separate
HTML page in any year, so none were followed/extracted here; their link
text and URLs are included above as they appear on each main page. All
age-group PDF links were spot-checked and returned HTTP 200 (not broken).

Each year also links to a "Complete Results" page, available in both HTML
(complete_results.htm) and PDF form. The HTML version is a very large
(700KB-900KB) plain-text dump of the full HY-TEK meet-manager results
report (every heat/event, not just age-group summaries) wrapped in a
<pre> tag. This is a different document from the "Results by Age Group"
breakdown and was not in scope for this extract; its link is preserved
above along with 2022-2025's added "Team Profiles" and "Unified" PDF
links. It returned HTTP 200 for all five years.

Broken/missing link: on the 2025 page only, "View meet website archive" is
plain text with no hyperlink (the equivalent text is a working link on the
2021-2024 pages, pointing to that year's meet-website archive). This
appears to be an oversight on the source site rather than a fetch failure
on my end.

Failed or unreadable sources: none. All five swim-YYYY pages and all
links referenced on them (Complete Results HTML/PDF, Team Profiles,
Unified, and the per-age-group PDFs) returned HTTP 200 when checked,
except the one missing (unlinked) "meet website archive" text noted above
for 2025.
